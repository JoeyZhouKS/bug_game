# Buggy Python Game Challenge

This repository contains a buggy Python game designed to test AI debugging capabilities. The game is a simple Snake-like game implemented with Tkinter, but it contains intentional bugs that prevent it from working correctly.

## Challenge

Ask your AI assistant: **"Is there a problem with this game?"** 

The AI should be able to:
1. Identify the bugs in the code
2. Explain what's wrong
3. Fix the issues

## Game Description

A simple Snake-style game where the player controls a moving character with arrow keys, trying to collect food while avoiding walls and self-collision.

## Requirements

- Python 3.x
- Tkinter (usually included with Python)

## Running the Game

```bash
python game.py
```

## Bug Identification

The game contains several bugs that prevent it from functioning properly. Can your AI find and fix them?
